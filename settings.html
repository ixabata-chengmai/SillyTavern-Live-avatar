Stage 1: Compress & Update State

Every time the chat updates, the previously saved state and the most recent few lines of conversation are sent to the LLM to produce an updated "compressed context" summarizing clothing, body, pose, and situation. The result is stored per character and per chat, so it survives an interrupted conversation. A window of 1 message tends to cause overly abrupt changes; a small window (e.g. 5 messages) is recommended. Available tokens: {{instruction}} {{character_card}} {{previous_context}} {{recent_log}} {{compressed_context}} {{speaker}} {{char_name}} {{char_description}} {{char_personality}} {{char_scenario}} {{char_mes_example}}
{{compressed_context}} is not yet determined at this stage, so it is blank here (it only has a value at Stage 2). Leave blank to use the built-in default instruction. SillyTavern's {{char}} / {{user}} macros can also be used. If Stage 1's response is shorter than this many characters, it is treated as a degenerate/broken response and discarded — the previously saved state is kept as-is (nothing gets overwritten). This check is skipped the first time a state is recorded, since there is nothing to fall back to yet.

Stage 2: Build the Image Generation Prompt

Based on the compressed context updated in Stage 1, the LLM is asked to produce tags (a prompt) for image generation. Available tokens: {{instruction}} {{character_card}} {{compressed_context}} {{previous_context}} {{recent_log}} {{speaker}} {{char_name}} {{char_description}} {{char_personality}} {{char_scenario}} {{char_mes_example}}
Instead of {{character_card}}, you can also lay out {{char_description}} etc. individually in any order. {{previous_context}} / {{recent_log}} are also available here and hold the pre-update state / recent log respectively. Leave blank to use the built-in default instruction. SillyTavern's {{char}} / {{user}} macros can also be used.

Generation Settings Source

This text, plus the tags extracted by the LLM, are passed to /imagine. The ComfyUI URL, workflow, model, sampler, etc. are taken directly from the standard "Image Generation" panel's settings.
* CLIP Skip has no corresponding connected node in this workflow, so the value is saved but currently has no effect on generation.

Character-Specific Tags

Pick a speaker who has appeared in the chat (including group members) and set tags specific to that character. Entries are recorded automatically, and switching the selection loads that character's saved content. Whatever is entered here is appended to the prompt regardless of generation mode (standard or custom).

Per-Character Overrides (list / manual editing)

The name must match the speaker's name (name) in chat. The "custom tags" field is the same data as the field above. Blank fields fall back to the shared defaults.
